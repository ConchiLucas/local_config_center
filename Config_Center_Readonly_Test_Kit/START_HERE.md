# 配置中心 · 只读展示 + 多媒体测试工作台

这是给开发 AI 和人工开发者的唯一入口。先阅读本文件，再按指定顺序实施。

## 本轮已经确认的目标

顶部是一级配置分组；左侧是当前分组的二级目录；主区是只读配置详情。一级分组可以是供应商、网关、本地服务或存储系统，不是硬编码的“AI 厂商列表”。

不出现：新增、编辑、删除、保存、重置、高级选项、全局搜索、头像、登录入口、通知等管理型界面。不要把禁用的输入框当作只读详情。详情使用标题、说明、标签与键值展示。

允许的交互：导航、测试输入、开始/停止测试、结果展开、图片放大、音视频播放与测试区全屏。测试的输入不是配置编辑，不能写回配置数据库。

推荐交互：主页面展示详情；每条配置有一个“测试”入口；点击打开右侧大尺寸测试工作台，可展开为全屏。不要另开“详情弹窗 → 测试弹窗”的两层套娃。图片放大可作为单独的查看层。

## 先查看原型

最简单：双击根目录的 `OPEN_PREVIEW.html`。这是自包含文件，无需 npm 或联网。它使用静态演示配置，可体验导航、对话排版、JSON、图片放大、音频播放、视频播放、数据库探针排版和 MinIO 媒体预览。

体验真实的“从数据库读配置”演示：

```sh
python3 RUN_DEMO.py
```

Windows 可执行 `py -3 RUN_DEMO.py`。脚本要求 Python 3.10 或更高版本，默认只监听本机。浏览器打开 `http://127.0.0.1:8765`。端口被占用时执行 `python3 RUN_DEMO.py --port 8766`。

数据库演示读取 `database/demo.sqlite3`，以只读方式打开。只开放配置 GET 查询；不提供配置写入 API。媒体请求支持 HTTP 字节范围。

## 必须理解的交付边界

这是一份可运行的界面原型和开发契约，不是已经对接用户生产环境的产品。

- **已完成**：数据驱动菜单、差异化只读详情、多配置条目、右侧测试工作台、全屏、流式样例、完整文本样例、JSON 树和源码、图片放大、真实可播放的 WAV/MP4 本地样例、数据库与存储专用结果组件、移动端布局、错误与停止状态。
- **未对接**：用户真实数据库、真实模型供应商、真实 MinIO、真实视频异步任务、生产鉴权、测试历史持久化。演示里没有真实密钥。
- 图片是前面提供过的固定背景素材；视频是对这张背景做缓慢推进得到的 5 秒样片；语音是离线合成的固定中文样例。它们与本次输入无关，页面已明确标注。
- `POST /api/test-runs` 明确返回 501，防止有人把尚未实现的适配器当作成功调用。当前测试样例逻辑在 `web/app.js`，生产化时必须替换，不能留下成功状态的伪装。
- 供应商菜单、模型名、能力标签均为演示注册，不表示真实厂商一定支持对应能力。不能从这个原型推断 Grok 或 Antigravity 的实际接口规格。

## 给开发 AI 的阅读顺序

1. `docs/01_PRODUCT_AND_VISUAL.md`：页面范围、导航、只读详情和视觉要求。
2. `docs/02_TEST_WORKSPACE.md`：每一种测试界面和结果渲染规则。
3. `docs/03_BACKEND_CONTRACT.md` 与 `docs/contracts.ts`：数据库读取、服务端执行、类型契约、安全边界。
4. `docs/04_ACCEPTANCE.md`：验收项目、实施阶段和必须向用户确认的真实接入信息。
5. `docs/ASSETS_AND_SOURCES.md`：素材尺寸、用途和官方技术资料。

先确认现有项目的框架与数据库结构，再把原型迁移进去。不要为了匹配本包强制把用户项目改成 Python 或 SQLite；本包使用这些只是为了零依赖演示。

## 实施原则

优先复用用户现有数据库中的配置，不创建平行的“另一套配置真源”。允许建立只读投影、字段映射和 provider adapter。厂商差异放在适配器；页面类型差异放在详情与结果组件；禁止全站到处写 `if provider === 'grok'`。

先完成“一个对话配置 + 一个图片配置”的真实闭环，再接 TTS、视频和本地基础设施。没有实际连接信息时，清晰列出缺少的环境变量或适配器，不编造成功结果。

保存结果或任务状态不等于编辑配置：测试运行记录应放在独立的运行数据存储中，配置数据仍然只读。

## 原型快捷体验

顶部切换 Antigravity Tool / Grok / 本地服务 / MinIO。左侧切换各自目录。点击“测试效果”或“测试连接”。输入后开始演示。对话支持流式、JSON、一次性三种快捷预设。输入 `#error` 可以查看失败状态。运行时可停止演示。收起面板后重新打开，同一页面会保留该配置的输入和结果；刷新页面会清空演示会话。

`screenshots/` 中是实际浏览器渲染截图，不是带有错误字段的生成式 UI 效果图。`docs/TEST_REPORT.json` 记录本次验证范围。自动化验证在 Chromium 完成；没有宣称验证 Safari 或真实供应商。
