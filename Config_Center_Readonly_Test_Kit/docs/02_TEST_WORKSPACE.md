# 02 · 多媒体测试工作台

## 选择：大侧栏，不做小详情弹窗

详情已经显示在主页面，再做详情弹窗会增加一层。小弹窗也不适合长对话、宽图、视频播放器与异步任务。因此“测试”直接打开右侧大工作台：桌面约 1040–1200px，主体左输入、右结果；可扩展全屏；窄屏全屏。

标题显示“图片测试 / 语音测试 / 对话测试”等，下面固定展示分组、配置名、模型标识与配置版本。不能在任务运行期间悄悄把绑定对象换成另一条配置。

输入和结果视图不是固定的万能表单。统一容器、统一运行状态、统一媒体组件，但输入组件和详情字段分类型实现。

## 输入与返回

| 类型 | 输入 | 结果呈现 | 查看动作 |
| --- | --- | --- | --- |
| 对话（流式） | 文本或消息列表 | 逐步追加的聊天内容 | 停止本次输出、滚动阅读 |
| 对话（完整） | 文本或消息列表 | 完成后显示完整消息 | 阅读，必要时复制 |
| JSON | 提示文本；需要时有业务明确给定的 schema | 折叠树 / 格式化 JSON，显示解析/约束检查结果 | 展开节点与切换源码 |
| 图片 | 提示文本；仅真实支持时可提供参考图 | 一张大图或多图网格，实际尺寸和格式 | 点击图片放大、缩放 |
| TTS | 要朗读的文本；默认使用数据库音色 | 原生音频播放器，朗读文本、时长与格式 | 播放、暂停、拖动 |
| 视频 | 提示文本；仅支持时提供参考图 | 封面、任务阶段、完成后的原生视频播放器 | 播放、暂停、拖动、全屏 |
| 数据库 | 默认不接受任意 SQL；选预设只读探针 | 状态、耗时、目标与探针结果 | 阅读结果 |
| MinIO | 受限对象名/前缀；或选一个受控探针 | 对象列表和按类型预览 | 图片放大、试听、看视频 |

浏览器音视频使用 `<audio controls>` / `<video controls playsinline>`；“结果能看”不是只打印 Base64、二进制、URL 或 JSON blob。播放器格式和 MIME 类型必须匹配实际数据。详见官方来源 [2][3]。

不自动播放有声音的内容。异步请求完成后用户点击播放是明确、可靠的交互；不能假设之前点击“开始测试”的手势会无限期覆盖之后的媒体自动播放。详见 [4]。

## 对话模式的正确建模

UI 保留用户要求的三个快捷选择：

- 流式返回：`delivery=stream, format=text`
- JSON 返回：`delivery=complete, format=json`
- 一次性返回：`delivery=complete, format=text`

它们是操作预设，不是三种永远互斥的底层能力。数据传输与内容格式分开存储，某个适配器将来支持 `stream + json` 时不必重建数据库。JSON 约束是否受支持、如何请求、是否成功解析或通过 schema 校验，要单独记录。

特别注意：HTTP 响应本身是 JSON 包装，不等于模型的内容是“结构化 JSON 输出”。流式返回的中间片段也可能暂时不是合法完整 JSON；最终聚合后再验证，或使用真正的增量解析器。

浏览器可逐块读取 Fetch 返回的 ReadableStream 来追加内容 [1]。不能把全部文本等到最后拿到后用打字动画伪装“真实流式”；本原型的打字效果只属于明确标注的模拟。

## 运行与结果生命周期

建议阶段：idle → submitting → queued / running → succeeded / failed / cancelled。仅适配器实际有百分比时显示百分比；不知道进度则显示“排队中”“生成中”，不要插入假进度。

长视频创建任务后保存 runId；前端用轮询或事件流拿状态。任务完成后再装载播放器。播放失败与生成失败是不同状态，例如过期链接不能把已生成任务改为“生成失败”。

关闭工作台只是收起视图，暂停页面媒体播放，不默认取消远端任务。重新打开恢复该配置的运行内容。生产版本刷新后可按 runId 恢复；本原型只在页面内存保留。

停止等待、停止浏览器接收、向上游申请取消、上游确认取消必须区分。不支持取消时明确提示“停止等待，上游可能仍在运行并计费”。只有确认后才显示“已取消”。

按钮防重复提交；真正的服务端还应使用幂等键。文本流中途断开，显示“输出中断”并保留已有文本，不自动把新的重试文字拼到旧回答后。

## 媒体结果实现边界

同一个任务可返回多个 output block；不要把一个 run 的结果类型只能设成 image 或 text。后续图文混合、多个音频分段、视频附带描述都用 block 列表扩展。

对于远端 URL、二进制、Base64、对象存储 key，由后端适配器转为安全可访问的 artifact。建议返回 assetId，由同源受控媒体接口或短时授权地址访问。大文件不要通过配置查询接口传递 Base64。

媒体代理不能是 `?url=任意地址` 的开放抓取器；只允许读取本次运行实际登记、当前用户被授权查看的 assetId。对象键也要按允许的 bucket/prefix 解析，不能映射成任意本地路径。详见 [5]。

结果空态、无输出、模型拒绝、超时、网络失败、不支持的格式、链接过期、服务端权限不足应各有可理解的提示。错误只显示脱敏摘要和请求编号，不能把供应商完整响应、密钥、内部堆栈原样渲染。
